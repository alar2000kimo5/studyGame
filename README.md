# Dragons & Heroes

一款使用 **Python + Pygame** 開發、玩法類似 **Friends and Dragons** 的戰術格子 RPG。

## 玩法說明

- **按住英雄拖曳**：英雄跟著滑鼠移動
- **拖過友方英雄**：即時交換位置，放開後統一觸發技能與攻擊
- **連環交換**：可一路換位置到敵人身邊
- **ESC**：取消拖曳

## 英雄技能（交換時觸發）

| 英雄 | 技能 | 效果 |
|------|------|------|
| 戰士 | 衝鋒斬 | 普通攻擊加成 |
| 法師 | 火球爆炸 | 全敵 AOE 傷害 |
| 治療師 | 神聖治癒 | 全隊回復 25 HP |
| 遊俠 | 狙擊箭 | 高額單體遠程 |
| 坦克 | 鐵壁防禦 | 獲得護盾 |

## 執行方式

```bash
pip install pygame
cd game
python main.py
```

## 專案結構

```
game/
├── main.py              # 遊戲入口
├── settings.py          # 常數與顏色設定
├── scenes/              # 場景（選關、戰鬥、關卡定義）
├── entities/            # 英雄與敵人
├── systems/             # 格子系統、回合管理
└── ui/                  # HUD 介面
```
