# Dragons & Heroes

一款以 **Friends & Dragons** 玩法為藍本的戰術格子 RPG，使用 **HTML5 Canvas + JavaScript** 製作，不需要安裝任何東西，手機直向與電腦都能玩。

## 怎麼玩

直接用瀏覽器開啟 `index.html`，或開啟單檔版 `dist/dragons-heroes.html`。線上試玩：https://claude.ai/artifact/9Cxf3iZ8ikZYBtzAq32kbF

（若要用本機伺服器：`python3 -m http.server 8000` 後開 `http://localhost:8000`。在網址後加 `#unlock` 可直接開放所有關卡。）

## 核心規則（與 Friends & Dragons 相同）

- **一回合只能拖曳一名英雄**。拖曳可八方移動、距離不限，但有 **5 秒時限**，時間到自動放開。
- **經過友方就交換位置**，可以連環交換把整隊排好。擁有「推擠」或「翻滾」天賦的英雄還能推開或穿過怪物。
- 放開後**所有英雄依序自動攻擊**：被拖的英雄最先出手，接著是最後一個被交換到的英雄，其餘依原本順序。想讓牧師先治療就最後再碰他。
- 三種攻擊方式：
  - **近戰**：攻擊相鄰格（十字或八方）的所有敵人。
  - **遠程**：每條線上的第一個目標；若第一個是友方就被擋住。
  - **魔法**：穿透整條線，打到線上所有敵人，友方不擋線。
- **三層克制**（詳見下方）：顏色、職業、種族。
- 怪物依**速度**由高到低行動，五種 AI：衝鋒（最少移動就攻擊）、戰術（打到最多人）、刺客（追殘血）、莫測（隨機）、迴避（保持距離）。嘲諷英雄會強制牽制怪物。
- 每個地牢有**多波怪物**，清光一波下一波從上方出現，英雄保持位置與 HP。

## 克制關係

| 層級 | 規則 | 倍率 |
|------|------|------|
| 顏色 | 紅 › 綠 › 藍 › 紅；光與暗互相克制 | ×1.5 / 被克 ×0.75 |
| 職業 | 攻擊方式三角：近戰 › 遠程 › 魔法 › 近戰（英雄與怪物都適用） | ×1.2 / 被克 ×0.85 |
| 職業專精 | 每個職業對一種怪物種族有額外加成（例：獵人→野獸 +30%、牧師→亡靈 +30%、元素使→惡魔 +30%） | +15% 到 +30% |
| 種族 | 英雄七種族各克制一種怪物種族、被一種克制，攻擊與被攻擊都算 | ×1.2 / 被克 ×0.85 |

怪物種族：獸人族、野獸、亡靈、龍族、魔像、惡魔。英雄種族對應：人類克獸人族、被惡魔克；精靈克野獸、被獸人族克；矮人克魔像、被龍族克；獸人克野獸、被亡靈克；龍裔克龍族、被魔像克；半身人克惡魔、被野獸克；天使克亡靈、被龍族克。戰役畫面的「克制表」按鈕可隨時查看，怪物資訊卡會列出誰克制牠。

## 地形

| 地形 | 效果 |
|------|------|
| 牆、岩石 | 擋住移動與射線，遠程與魔法都打不穿 |
| 冰 | 踩上去會往同方向一路滑到底，撞到東西或離開冰面才停 |
| 火 | 回合結束站在上面受 10% 最大 HP 傷害並灼燒 |
| 泥 | 怪物經過移動力 -1，英雄拖曳經過每格扣 0.5 秒時限 |
| 河 | 地面單位不能進入，不擋射線；橋可通行 |
| 虛空 | 戰場之外的格子，任何單位都不能進入，射線可穿過。戰場因此不一定是方形 |
| 尖刺陷阱 | 停在上面的單位受 15% 最大 HP 傷害 |
| 毒霧陷阱 | 回合結束站在上面會中毒 3 回合 |
| 炸彈陷阱 | 踩到就爆炸，自己與周圍八格受 20% 最大 HP 傷害，之後消失 |
| 傳送門 | 停在上面會被傳送到另一個傳送門 |
| 能量水晶 | 回合開始站在上面的英雄獲得 30 大絕招能量 |

**飛行**單位（天使、蝙蝠、鷹身女妖、龍族等）無視冰、火、泥、河與所有陷阱，但不能穿牆或進入虛空。怪物 AI 會避開冰、火與陷阱，自動戰鬥也會。

## 專屬武器

每位英雄一把，只有本人能裝。效果分兩層，並隨專武等級（1～5，用同名專武強化，每級 +15%）成長：

- **種族效果**（同種族共通）：人類「多才」、精靈「疾影」、矮人「礦心」、獸人「血怒」、龍裔「龍息」、半身人「幸運」、天使「聖翼」。
- **獨有特性**：每位英雄有三把不同的專武（共 240 把），各有自己的名字與特性，例如處決、連鎖、反擊、減速、暈眩、全隊加成、地形免疫等；同時只能裝一把，在武器欄切換。

專武只能從武器召喚取得（5%，十連保底一把，隨機抽到三把之一）。強化需要同一把專武。

## 養成系統（與 Friends & Dragons 相同的結構）

- **英雄卡**：左上顯示顏色、種族與隊長加成；右上顯示攻擊模式與輔助模式；下方是天賦列、等級、攻擊／防禦／生命、六格裝備欄與昇華、合併、退役、編隊按鈕。
- **升級**：消耗同色經驗（不足時用彩虹經驗），上限 75 級，昇華後 85 級。
- **天賦**：每位英雄有 1 個職業天賦，再依星數解鎖 1 到 5 個基本天賦，解鎖消耗「星數」個天賦代幣。
- **裝備**：武器、護甲、頭盔、靴子、戒指、護符六個部位；稀有度魔法／史詩／神話／傳說，分別加成 5% / 8% / 12% / 16% 屬性。武器稀有度會在角色身上顯示光暈。
- **昇華**：集滿裝備、達到等級並付金幣後可昇華：消耗所有裝備、等級減半，換取基礎屬性 +20%、上限 85 級與昇華天賦。
- **隊長加成**：隊伍最左邊的英雄是隊長，同顏色隊友獲得攻擊與防禦加成。
- **輔助模式**：牧師、聖騎士、德魯伊、吟遊詩人、公主等輔助職業行動時，對輔助模式內的友方施加治癒、延遲治癒、鼓舞或結界。
- **兵營**：重複英雄可合併（每次 +4% 屬性，最多 5 次）或退役換靈魂印記與彩虹經驗。
- **召喚之門**：寶石召喚（1★ 40%、2★ 30%、3★ 19%、4★ 8%、5★ 3%），靈魂召喚用退役得到的靈魂印記，1★ 到 5★ 都會出現但高星機率較高（1★ 25%、2★ 28%、3★ 25%、4★ 15%、5★ 7%）。兩者都可單抽或十連。
- **戰利品**：通關獲得金幣、寶石、彩色經驗，並有機率掉落裝備與天賦代幣，首次通關有額外加成。
- **商店**：寶石換天賦代幣、彩色經驗與各稀有度裝備箱。進度存在瀏覽器的 localStorage。
- **一鍵裝備**：英雄卡與編成畫面都有按鈕，自動把背包裡每個部位最好的裝備（專武優先）換上。
- **自動戰鬥**：戰鬥頂欄的「自動」開關。AI 會搜尋每位英雄最多 4 步的移動與交換路線，以預期傷害、擊殺、治療、怪物威脅與地形評分，選最好的一手自動拖曳；手動拖曳任一英雄即取消。

## 專案結構

```
index.html            # 入口
src/config.js         # 尺寸、規則常數、配色
src/grid.js           # 格子座標、八方 BFS
src/patterns.js       # 近戰／遠程／魔法攻擊模式
src/data/             # 英雄、怪物、天賦、裝備、專武效果、關卡生成（160 關）
src/meta.js           # 玩家存檔與養成：升級、天賦、裝備、昇華、合併、召喚、戰利品
src/ui.js             # 共用介面元件與可捲動畫面
src/screens/          # 兵營、英雄卡、隊伍編成、召喚、商店
src/units.js          # 單位類別
src/combat.js         # 傷害計算（顏色克制、防禦層數、天賦加成）
src/ai.js             # 五種怪物 AI
src/sprites.js        # 程式繪製的 Q 版英雄與怪物
src/fx.js             # 飄字、投射物、光束等特效
src/autoplay.js       # 自動戰鬥：搜尋最佳拖曳路線
src/battle.js         # 戰鬥場景：拖曳、行動順序、波次、結算
src/campaign.js       # 戰役地圖
src/main.js           # 主迴圈、畫布縮放、輸入
tools/build.js        # 打包成單檔 dist/dragons-heroes.html
```

執行 `node tools/build.js` 可重新產生單檔版本。
